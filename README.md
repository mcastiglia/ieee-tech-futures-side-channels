# Hardware Side Channel Demo - ChipWhisperer - Public Release Simulation
Design of Resilient Architectures for Computing Lab - University of Central Florida Department of Electrical Computer Engineering

Director, Mike Borowczak, PhD

Authors: Franco Mezzarapa, Michael Castiglia, Mike Borowczak

## What Hardware do you Need?

None, this repository provides a simulation of the real ChipWhisperer hardware.

## Prerequisites

- Python 3.10+

## Install

```bash
git pull https://github.com/mcastiglia/ieee-tech-futures-side-channels.git
cd ieee-tech-futures-side-channels
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open:

- `http://127.0.0.1:5000`
